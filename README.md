# Adam Harris — Official Website

Official website for Adam Harris, UK pop artist from Leicester.

## About

This is a static HTML/CSS website for Adam Harris, featuring:

- Latest releases and discography (Wavelength, Bad Decisions)
- Embedded Spotify and YouTube players
- Music videos section
- Artist biography
- Collaboration and contact info
- [The Rooms](/the-rooms/) — a dedicated fan section

## Stack

- Plain HTML, CSS, and vanilla JavaScript
